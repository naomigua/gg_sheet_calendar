# 📋 Instructions pour le Template

## Obtenir le template

### Option 1 : Lien direct (recommandé)
Cliquez sur ce lien pour créer votre copie :
👉 [Créer une copie du template](https://docs.google.com/spreadsheets/d/VOTRE_ID/copy)

### Option 2 : Création manuelle

Créez une Google Sheet avec ces colonnes dans l'ordre :

1. Title
2. Start Date
3. Start Time
4. End Date
5. End Time
6. All Day
7. Description
8. Location
9. Guests
10. Calendar ID
11. Status
12. Event ID
13. Processing Log
14. Last Updated
15. Create (case à cocher)
16. Modify (case à cocher)
17. Delete (case à cocher)

### Ajouter les cases à cocher
1. Sélectionnez les cellules des colonnes Create/Modify/Delete
2. Menu : **Données → Validation des données**
3. Critères : **Case à cocher**
